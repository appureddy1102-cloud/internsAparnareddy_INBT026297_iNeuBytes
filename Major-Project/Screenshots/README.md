## Good screenshot practice

1. Show the application context, not just a cropped number.
2. For SQL, show both the query and result grid.
3. Use readable zoom and remove private desktop content.
4. Use descriptive names such as `SQL_Q3_Category_Sales.png`.
5. Insert the important images into the single combined Google Doc with a caption and one-sentence interpretation.
6. Do not label generated charts as application screenshots.
