EXECUTIVE SUMMARY
This project analyses historical pharmaceutical sales quantity for eight Anatomical Therapeutic Chemical (ATC) medicine categories. The business objective is to understand category and time-based demand patterns and provide cautious evidence for inventory-planning discussions.

The supplied data contains hourly, daily, weekly and monthly versions of the same underlying series. These granularities must not be added together. The main analysis uses 2,106 continuous daily records from 2 January 2014 to 8 October 2019. Hourly data is used only for hour-of-day analysis.

Headline results:
• Total recorded quantity: 127,595.50.
• Average total quantity per observed day: 60.59.
• Leading category: N02BE with 63,005.40 quantity, equal to 49.38% of the total.
• Top-three categories N02BE, N05B and R03 contribute 73.09%.
• Highest complete calendar month: January 2019 with 2,875.16.
• Highest weekday average: Saturday with 65.67 per observed day.
• Complete calendar months: 68.

Metric warning: “sales” in this project means source-recorded quantity, not revenue. The dataset has no price, revenue, profit, current stock, supplier lead-time or expiry fields.

DATASET AND DATA DICTIONARY
Source files:

ATC category descriptions:

Important engineered fields:

TASK 1 — SQL-BASED DESCRIPTIVE ANALYTICS AND REPORTING
Objective
Inspect, clean and analyse the daily dataset using MySQL, then calculate descriptive and aggregate measures that answer business questions.

Method
1. Create a staging table with text fields so invalid source values can be inspected before conversion.
2. Load salesdaily.csv using LOAD DATA LOCAL INFILE after changing the local path.
3. Check blanks, duplicate dates, invalid dates, non-numeric values, negative values and calendar consistency.
4. Create a clean daily table with DATE and DECIMAL fields and a generated Total_Quantity column.
5. Create a long view with one row per date/category and a monthly view derived from daily data.
6. Use SUM, AVERAGE, STDDEV_SAMP, COUNT, MIN, MAX, GROUP BY, HAVING, CASE, window functions and filtering for analysis.
7. Use the long view for category analysis. A join is not necessary for the main calculations because category descriptions are supplied in the data dictionary/lookup; joining the lookup is optional and does not change the numerical results.

Example overall query:
SELECT
  ROUND(SUM(total_quantity), 2) AS total_sales_quantity,
  ROUND(AVG(total_quantity), 2) AS average_daily_quantity
FROM pharma_sales_daily;

Data-quality findings
• No blank cells, exact duplicate rows, duplicate dates, invalid dates, negative category values or missing daily timestamps were found.
• The daily Hour field contains only 190, 248 and 276. It is not time-of-day and was excluded from the clean analytical table.
• Hourly totals reconcile with daily totals within floating-point tolerance.
• All 302 weekly rows reconcile with daily aggregation when treated as weeks ending Sunday.
• Only 37 of 70 supplied monthly rows match daily aggregation within 0.01 across all categories.
• January 2017 demonstrates the issue: the supplied monthly total is 1.00, whereas daily aggregation gives 2,699.60. Monthly results are therefore derived from daily data using one consistent rule.

Business insights
N02BE deserves close historical availability monitoring because it accounts for almost half of recorded quantity. This does not prove highest revenue or clinical importance. N05C and R03 require intermittent-demand review because simple averages hide many zero days. Partial months must not be compared directly with complete months.

TASK 3 — BUSINESS INTELLIGENCE DASHBOARDS IN POWER BI OR TABLEAU
Objective
Prepare a reusable long-format data model, define consistent KPIs, and design an interactive dashboard with time and category filters.

Data preparation
The BI-ready file pharma_sales_long.csv contains 16,848 rows: 2,106 dates × 8 categories. Sale_Date and Month_Start are dates, Quantity is decimal, Is_Complete_Month is Boolean, and category/calendar labels are text. The file preserves zero-quantity date/category rows.

Power BI measures
• Total Quantity = SUM('Sales'[Quantity]).
• Days in Selection = COUNTROWS(VALUES('Date'[Date])).
• Average Daily Quantity = DIVIDE([Total Quantity], [Days in Selection]).
• Peak Daily Quantity = MAXX(VALUES('Date'[Date]), [Total Quantity]).
• Previous Month Quantity = CALCULATE([Total Quantity], PREVIOUSMONTH('Date'[Date])).
• Category Share % compares each category with all categories for the same selected dates.

Tableau calculated field
Average Daily Quantity:
SUM([Quantity]) / COUNTD([Sale_Date])

Dashboard design
• KPI cards: Total Quantity, Average Daily Quantity and Peak Daily Quantity.
• Monthly line chart: Month Start and Total Quantity, filtered to complete months.
• Category bar chart: ATC_Category and Total Quantity, sorted descending.
• Weekday chart: Weekday and Average Daily Quantity, sorted Monday to Sunday.
• Filters: Year and ATC_Category; optional Weekday.
• Display a clear note that quantity is not revenue and that the data is historical.

Business insights
A shared long dataset and consistent metric definitions allow SQL, Excel, Power BI and Tableau to produce comparable results. The same 127,595.50 total and 49.38% N02BE share should be used as validation checks.

MAJOR PROJECT — END-TO-END ANALYTICS CASE STUDY
Business problem
A pharmacy needs to understand historical demand by medicine category and time period. Historical evidence can support inventory discussions, but this dataset alone cannot produce a safe reorder quantity.

Objectives
1. Establish a documented and reproducible source of truth.
2. Inspect and clean raw data without deleting source evidence.
3. Calculate descriptive statistics and category/time aggregates.
4. Visualise monthly, category, weekday and hourly patterns.
5. Design an interactive BI dashboard with consistent KPIs.
6. Present evidence-based recommendations with explicit limitations.

Exploratory analysis
Category: N02BE contributes 49.38%, N05B 14.61% and R03 9.10%. Together they contribute 73.09%. N05C contributes 0.98% and has the highest zero-day frequency.

Monthly: January 2019 is the highest complete month at 2,875.16; July 2017 is the lowest at 1,251.15. Across complete months, January has the highest average monthly quantity and July the lowest. This is a descriptive pattern based on only five to six observations per calendar month, not a validated forecast.

Annual: Complete years 2015–2018 fluctuate rather than showing a consistent upward or downward pattern. The year 2019 is partial and must not be interpreted as a full-year decline.

Weekday: Saturday has the highest average at 65.67 and Thursday the lowest at 57.18. Saturday is approximately 14.85% higher, but the analysis does not establish a cause.

Hourly: The highest average occurs at 19:00, with 5.38 quantity per observed hour. Overnight zero or near-zero values may reflect pharmacy operating hours rather than absent patient need.

Variability: N05C has zero quantity on 67.90% of days and R03 on 22.98%. The 95th percentile and standard deviation describe historical variation but are not automatic safety-stock targets.

Recommendations
1. Begin availability review with high-share categories, especially N02BE, while retaining clinical and operational review.
2. Use complete-month planning views and keep partial periods explicitly labelled.
3. Treat N05C and R03 as intermittent-demand examples and include zero-day frequency, pack size and expiry in review.
4. Confirm historical January, Saturday and evening patterns with current pharmacy evidence before changing inventory or staffing.
5. Add current stock, stock on order, lead time, service-level target, pack size, minimum order quantity, expiry, price and supplier constraints before calculating reorder rules.
6. Reconcile future daily, weekly and monthly extracts automatically and document corrections.
7. Use dashboards for monitoring and discussion, not automatic purchasing.

Limitations
• Data comes from one pharmacy and may not generalise.
• The series ends in October 2019 and does not represent current 2026 demand.
• The final year is incomplete.
• ATC aggregates hide brand, strength, formulation and pack differences.
• No financial or current-inventory fields are available.
• Kaggle states that missing-data treatment and outlier treatment were already performed.
• Supplied monthly data does not consistently reconcile with daily data.
• Weekday, monthly and hourly associations are descriptive, not causal.
• No forecast, model accuracy, reorder point or purchase quantity is invented.
• Results are not prescribing advice; pharmacist and regulatory review remain necessary.

Major Project learning
The most important technical lesson is that data preparation affects business conclusions. Reconciling time grains, preserving raw data and flagging partial periods prevents misleading comparisons. The most important business lesson is that historical quantity is only one input to inventory planning.
